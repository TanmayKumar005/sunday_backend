# S.U.N.D.A.Y. Frontend

React + Vite student-facing MVP for the S.U.N.D.A.Y. adaptive learning backend.

## Run

From `frontend/`:

```powershell
npm install
copy .env.example .env
npm run dev
```

Backend should be running at `http://127.0.0.1:8000` by default.

The frontend uses real curriculum, questions, assessment, adaptation, result and progress data from the FastAPI backend. It does not contain mock learning data.
